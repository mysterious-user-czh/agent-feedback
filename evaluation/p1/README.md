# P1 分层黄金集

## 覆盖基线

- 从审计副本完整枚举 34 个非空主会话、6,793 条消息。
- 固定种子 20261115 选择 20 个会话，每个会话至少 1 个观测点。
- 共 40 点：新任务 10、纠正 6、委派子事件 8、assistant 延续 8、tool 延续 8。
- 20/20 会话、40/40 点覆盖，差集为 0。

## 独立复核后指标

- 边界 TP 7、FP 3、FN 3、TN 27。
- Precision 70%、Recall 70%、F1 70%。
- 关系准确率 34/40（85%）。
- 任务归属准确率 32/40（80%）。
- 差异 8 条。
- 无法判定比例由预测逐条实算，当前 0/40；本批无歧义黄金例，不能证明歧义检测有效。

## 样本口径与 95% 置信区间

黄金正边界为 10 个（TP 7 + FN 3），预测正边界也是 10 个（TP 7 + FP 3）；不是“40 点都是边界”。

| 指标 | 点估计 | 95% 置信区间 |
|---|---:|---:|
| Precision | 7/10 = 70% | 39.7%–89.2%（Wilson） |
| Recall | 7/10 = 70% | 39.7%–89.2%（Wilson） |
| F1 | 70% | 37.5%–100%（按会话整组 bootstrap） |
| 关系准确率 | 34/40 = 85% | 70.9%–92.9%（Wilson） |
| 任务归属准确率 | 32/40 = 80% | 65.2%–89.5%（Wilson） |

F1 bootstrap 固定 10,000 次、种子 20261115，以整个 session 为重采样单位。区间只反映有限抽样不确定性，不覆盖标注偏差、会话选择偏差或开发集过拟合；宽广区间说明不能把小样本点估计当作稳定总体性能。

独立只读复核同意原 7 条差异，并新增消息 8846 的 owner 修正：8835 已开启新任务，后续普通执行消息不能无血缘归回 8678。修正后归属准确率由 82.5% 降为 80%。

## 证据边界

初始标注由同一 Agent 完成，随后由未参与标注的独立只读复核者审查全部 40 点。仍不是人类标注、隔周盲标、人际一致性或独立测试集证据。最早有效隔周复标日期为 2026-11-22。

40 点是开发／诊断集，不是总体性能估计：正边界仅 10 个，会话分布集中，分层来自候选类别。不能再用这 40 点同时调参与宣称泛化提升。

## 文件

- `golden.json`：独立复核后的 40 点标签。
- `metrics.json`／`metrics.md`：指标、置信区间与全部 8 条差异。
- `score.py`：仅依赖 Python 标准库的可复现评分入口。
- `predictions.json`：40 点脱敏预测输入，不含消息正文；运行 `python evaluation/p1/score.py` 可重建两个指标文件。
- `independent-review.md`：独立复核范围、分歧和抽样限制。
- `segmentation-improvement-freeze.md`：确定性完整性检查、待验证语义假设和防过拟合方案。
- `second-review.json`：此前同评审者第二遍记录。
- `session-inventory.json`：34 会话完整枚举。

原始消息全文不进入交付包。
